Ask OpenDesigner about your system

Ask in your own words. Each answer picks a part made ahead of time, then fills it while the data arrives. Colours follow meaning: green passes and red is broken.

The data is real. It comes from OpenDesigner's own engine, component library and glossary, run on a small sample app: a pricing page with three mistakes left in on purpose. Fixes and changes go to a scratch copy, and Undo puts them back.
